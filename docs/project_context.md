# Heaven Life — Project Context

> Full context of the project, generated by reading every HTML/CSS/JS file and the asset tree.
> Last updated: 2026-11-15

## 1. What it is

Marketing/portfolio website for **Heaven Life** ("HEAVEN LIFE for Constructions, Decorations, and Exports"), an Egyptian construction, interior design and 3D-finishing company based in **New Cairo, Fifth Settlement (Arabella), Egypt**.

- Canonical domain: `https://heavenlife.construction`
- Credit: "Crafted by A² - Ahmed & Ahmed" (meta author + footer `© 2025 Crafted by A²`)
- Language: UI content in **English**; SEO meta description/keywords/image `alt` text in **Arabic** (+ English keywords).
- Business: building, real estate development, 3D decoration/finishing techniques, design & renovation of commercial centers/hospitals, supply services.

## 2. Tech stack

Pure static site — **no build step, no framework, no package.json, no backend, no git repo**.

- HTML5 / CSS3 / vanilla JavaScript
- CDN libraries:
  - **AOS 2.3.4** (scroll animations; home page) — jsdelivr
  - **TypeIt 8.7.1** (typewriter effect on descriptions) — jsdelivr
  - **Font Awesome 6.0.0** (icons, home page + project description markup) — cdnjs
  - **Google Fonts Roboto** (services page)
- Other fonts: Arial / Segoe UI fallbacks.
- Images: all `.webp`.
- Open `index.html` (meta-refresh redirect → `html/home.html`) or serve the folder with any static server.
- `.claude/settings.json` enables the `frontend-design` plugin.

## 5. Data model — how projects work

All project data lives in **one JS array**: `js/template-of-project.js` → `const projects = [...]` (~51 KB, 13 entries, global variable).

Fields per project: `id`, `sector`, `client`, `role`, `title`, `mainImage`, `gallery` (array of 4 image paths), `location`, `date`, `description` (HTML string in a template literal, using classes like `project-header`, `project-stats`, `feature-grid`, `material-specs`, etc., with Font Awesome icons).

Flow:
1. Cards in the HTML are static `<a href="template-of-projects.html?id=N">` with empty `<img>`/`<h3>`/`<p>`.
2. Loader scripts (`projects-loader.js`, `updates-loader.js`, `section-projects-loader.js`, `section-updates-loader.js`) parse `id` from the href, look it up in `projects`, and fill image/title/subtitle.
   - projects page: subtitle = `role`; updates page: `role | date`; home "Our Work": `role | sector`; home "Latest Updates": `role | date`.
3. `project-details.js` reads `?id=` from the URL, fills the detail page, handles the image modal. If not found → "Project Not Found".

**To add a project:** add an object to `projects` (next id), create `assets/id-N/` with `<name>-m.webp` + `-1..-4.webp`, add a card `<a>` in the relevant HTML page(s).

## 9. Known issues / things to watch

1. **Missing files referenced:** `css/gallery.css` (linked in `home.html`) and `js/projects-filter.js` (script in `projects.html`) do not exist → 404s.
2. **`latest-updates.js`** expects filter `<select>` elements that aren't in the markup → `addEventListener` on `null` throws a console error.
3. **Duplicate `id="main-image"`** on every card (invalid HTML; also the same id as the hero image on the detail page).
4. **Project 2 description** has malformed HTML (`< div class= "project-overview" >`); project 11 title duplicates project 2's.
5. **Header/footer duplicated** in every page; `header.html` has a stray `>` after the logo `<img>` and is unused. `script.js` and `header.js` are near-duplicates.
6. `about-us.html` has stray `</span>` tags in headings; `projects.js` and `header.js` are unused.
7. `<meta name="robots" content="HeavenLife, Construction">` is not a valid robots directive (should be e.g. `index, follow`).
8. `data-location` on cards (e.g. `Giza`, `Katameya`) doesn't always match the project's real `location`.
9. The home page loads `template-of-project.js` (51 KB) and `project-details.js` only to resolve card data; `project-details.js` would error on the home page for missing detail elements only if `projects.find` succeeds with an id (no `?id=` → falls into the "Project Not Found" branch that writes to missing elements).
10. Detail-page meta icons all use the same `fa-map-marker-alt` icon; Font Awesome isn't linked on `template-of-projects.html`, so icons don't render there.
11. No contact form; contact is via email/phone/WhatsApp only.

## 10. Conventions to follow when editing

- Keep relative paths as `../assets/...` / `../css/...` / `../js/...` from files in `html/`.
- Keep Arabic SEO `alt` text pattern on images; use `.webp`.
- New pages: copy header/footer from an existing page, include `header.css` + `responsive.css` + `script.js`.
- Project content changes go only in `js/template-of-project.js`; card titles/subtitles are generated from it.
